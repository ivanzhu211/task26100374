# examgen — 可复现的重考组卷库

纯 Python 标准库实现，无第三方依赖。组卷同时满足主题与难度配额，
尽量避免考生见过的题；随机性（SHA-256 成本）只用于同等避重效果下的选择。

## 快速开始

```python
from examgen import Question, Interval, assemble

pool = [
    Question("q1", 1, {"代数"}),
    Question("q2", 2, {"代数", "几何"}),   # 多标签题，入选后只计入一个主题
    Question("q3", 2, {"几何"}),
]

result = assemble(
    pool,
    2,                                        # 试卷题数 N
    {"代数": Interval(1, 1), "几何": Interval(1, 1)},   # 主题配额闭区间
    {1: Interval(1, 1), 2: Interval(1, 1),    # 难度配额闭区间（须覆盖 1..5）
     3: Interval(0, 2), 4: Interval(0, 2), 5: Interval(0, 2)},
    required={"q1"},          # 必选题
    forbidden={"q3"},         # 禁选题
    history=[{"q1", "q2"}, {"q2"}],   # 历史试卷（题ID集合的列表）
    seed=7,                   # 非负整数种子
)

if result.ok:
    for a in result.assignments:
        print(a.question_id, "->", a.topic)   # 题ID 及其计额主题
else:
    print("无解")   # result.ok 为 False 表示不存在合法卷
```

配额也可直接传 `(下界, 上界)` 元组，例如 `{"代数": (1, 1)}`。

## 规则与最优性

- 每题有唯一字符串 ID、难度 1..5、一个或多个主题标签。
- 每道入选题从自己的标签中选择一个且仅一个计额主题；难度按题目自身属性计数。
- 合法卷满足全部主题/难度配额、包含全部必选题、不含禁选题、题目不重复。
- 只要存在合法卷，`assemble` 必然找到，并按字典序精确最小化三级成本：
  1. 入选题中曾出现在任意历史卷的题目数；
  2. 入选题在所有历史卷中的出现次数之和（同一题在多份历史卷中分别计数）；
  3. 入选题的随机成本之和，每题随机成本为
     `SHA-256(f"{seed}:{题目ID}")` 摘要按无符号大端整数解释的值。
- 结果对相同输入集合与 seed 完全确定，与题池、标签、历史卷的输入顺序无关。

非法输入（难度越界、空标签、重复 ID、必选与禁选交集、配额区间倒置、
难度配额未覆盖 1..5、标签缺少主题配额、负 seed 等）抛出 `ValueError`。

## 实现说明

`assemble` 使用动态规划：状态为已选题数、各难度计数、各主题计数
（超过配额上界的分支直接剪枝），按三级成本字典序保留每个状态的最优解。
成本为 Python 整数元组，比较精确无浮点误差。

## 运行测试

```sh
python3 -m unittest test_examgen -v
```

测试包含：多标签题改变计额归属的交叉配额实例（含必选/禁选题）、
单看可行合起来无解的实例、对小题池的穷举枚举对照（含历史题不可避免
与打乱输入顺序的可复现性）、成本优先级与输入校验等。
